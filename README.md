# RO General Map EXP Tool

เครื่องมือช่วยเลือกแมพเก็บเลเวลจาก EXP ต่อมอน, HP, จำนวนมอน และความหนาแน่นของพื้นที่เดิน

**เปิดใช้งาน:** [RO General Map EXP Tool บน GitHub Pages](https://econds.github.io/ro-leveling-map/)

หากเปิดจากไฟล์ในเครื่อง ให้เปิด `index.html` ได้โดยตรง หรือใช้ `python -m http.server 8765` แล้วเปิด `http://127.0.0.1:8765/`

## วิธีใช้

1. ตั้ง `Player Level` และ `Party Size` (ค่าเริ่มต้น 1 คน)
2. เลือก `Spotlight Event`
   - `Auto` เลือกรอบที่กำลังใช้งานตามเวลาไทย
   - `No event` ใช้ EXP และจำนวนมอนปกติ
   - เลือกรอบเก่าเองเพื่อเปรียบเทียบผลของกิจกรรม
3. ใส่ Server EXP Up, Gear, ไอเทมบัฟ และโบนัสเผ่าที่ใช้อยู่จริง
4. ใช้ช่องค้นหาเพื่อกรองแมพ แล้วคลิกชื่อแมพหรือชื่อมอนเพื่อดูรายละเอียด

ค่าที่กรอกจะบันทึกไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น กด `คืนค่าเริ่มต้น` เพื่อล้างค่า บัฟและโบนัสเผ่าทั้งหมดเริ่มที่ 0% สามารถกด `คัดลอกลิงก์การตั้งค่า` เพื่อส่งค่าที่กำลังเลือกให้ผู้อื่นได้

## อ่านตารางอย่างไร

- **Final EXP / ตัว** คือ EXP ต่อมอนหลังรวม Spotlight, level penalty, ปาร์ตี้ และบัฟแล้ว แสดงเป็นตัวเลขเต็มเพื่อให้เทียบกับในเกมได้
- **EXP / 1M HP** ใช้เทียบ EXP กับเลือดที่ต้องตี
- **คะแนนพื้นที่** รวม Final EXP กับความหนาแน่นมอน ใช้จัดอันดับความคุ้มของพื้นที่ ไม่ใช่ EXP ต่อชั่วโมง
- ค่าบนตารางแมพเป็นค่าเฉลี่ยถ่วงตามจำนวนมอน หากต้องการเทียบกับในเกมให้ดูแถวของมอนชนิดนั้นในรายละเอียด
- Spotlight เพิ่มเฉพาะมอนและแมพที่ระบุในประกาศ มอนที่ไม่อยู่ในรายการยังใช้ฐานปกติ

พื้นที่เดินคำนวณจากไฟล์ GAT ของแมพ จึงไม่เท่ากับพื้นที่เกิดมอนจริง และยังไม่รวมเวลาเดิน, การวาร์ป, respawn หรือผู้เล่นอื่น แมพที่ไม่มีข้อมูล GAT จะไม่ถูกจัดอันดับด้วยคะแนนพื้นที่

## Daily Dungeon และ EP20

Daily Dungeon 6th Anniversary 2026 เก็บไว้เป็นข้อมูลย้อนหลัง ค่าเริ่มต้นซ่อนไว้ เลือกได้จาก `Daily Dungeon ย้อนหลัง` เมื่อต้องการเทียบกับแมพปัจจุบันหรือซ้อมคำนวณรอบเดิม

มีข้อมูล EP20 จำนวน 9 แมพจากประกาศ [RO Thailand: Episode 20 Map & Monster](https://ro.gnjoy.in.th/episode-20-the-immortal-map-monster/) และ Spotlight ปี 2025–2026 จากประกาศกิจกรรมที่เกี่ยวข้อง ข้อมูลกิจกรรมที่หมดอายุยังเลือกดูได้ แต่ไม่ถูกใช้โดยอัตโนมัติ

วิธีเข้าแมพในรายละเอียดเป็นข้อมูลช่วยวางแผน เช่น Warp Portal, World Moving Ticket หรือเควส ควรตรวจเงื่อนไขจริงในเกมก่อนเดินทาง โดยเฉพาะแมพ EP19/EP20

ข้อมูล EXP, HP, จำนวนมอน และแผนที่ใช้เพื่อการเปรียบเทียบ อาจต่างจากเซิร์ฟเวอร์หรือแพตช์ที่กำลังเปิดอยู่
