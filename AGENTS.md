# Spotlight update workflow

When a new GGT event, announcement image, or revised image is provided or discovered for this project:

1. Archive the original image and URL. Record the printed monster name, level, map, Normal Base/Job EXP, and Event Base/Job EXP as source data.
2. Match each row to the existing map and monster by name, level, and map. Compare its Normal EXP with the current No event base and earlier GGT snapshots. Check other available sources, including Divine Pride thRO and iRO when they publish a comparable value. Record the source URL and server or region for every comparison.
3. Treat GGT as the primary source for GGT event values. Keep the printed fields (such as sourceMap and sourceName) separate from any runtime map or name mapping. Do not infer a permanent No event base change from an event multiplier alone.
4. Before applying a new event or changing a base value or map mapping, give the user a concise comparison: current base, new GGT Normal and Event values, earlier GGT values, values from other sites, any unmatched or conflicting rows, and the proposed interpretation with source links. Let the user decide how to handle differences. Report explicitly when no differences were found.
5. After the user's decision, update generated data, source notes, and the Spotlight audit record together. Preserve unresolved differences in the report.
